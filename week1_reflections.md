# Week 1 reflections
We review Java Object-Oriented Design (OOD).
The four main characters in OOD are encapsulation, inheritance, polymorphism, and access modifiers. 
The teacher also mentioned different access modifiers, such as public, private, and protected. 
Additionally, the teacher used the Lannister family to illustrate the concept in Java that one class cannot inherit multiple father classes.
The class has helped me review the basic Java syntax in an engaging way!
